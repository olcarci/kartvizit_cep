# Kartvizit Cep 1.5.0+22 — Hızlı işlemler

Bu paket gönderdiğiniz 1.4.1+21 kaynaklarından hazırlanmıştır. Tasarım, fontlar, OCR ve arşiv servisi korunmuştur.

1. Mevcut proje klasörünü yedekleyin ve çalışan flutter run oturumunu q ile kapatın.
2. ZIP içeriğini mevcut proje klasörüne birleştirerek kopyalayın. Projeyi veya mevcut dosyaları topluca silmeyin.
3. Sırayla flutter pub get, flutter analyze, flutter test çalıştırın.
4. flutter run ile yeniden derleyin; yeni native eklenti için hot reload yeterli değildir.

Yeni url_launcher bağımlılığı için pubspec.lock kullanıcı ortamında flutter pub get ile güncellenmelidir. Güncellenen kilit dosyasını commit'e dahil edin.

## Gerçek cihaz kontrolü
- Galeriden bir kart açın: Ara, WhatsApp’tan yaz, E-posta gönder, Web sitesini aç, Adresi haritada göster.
- Telefon/e-posta/web/adres alanını değiştirip düğmenin yeni değeri kullandığını kontrol edin.
- Birden fazla numarada seçici açılır; Vazgeç hiçbir işlem başlatmaz. Cep alanındaki numaralar önce listelenir.
- Boş/geçersiz alanlar pasiftir. WhatsApp hesabının varlığı önceden doğrulanmaz; wa.me bağlantısı ilgili uygulama veya web sayfasını açar.
- iPhone'da Apple Haritalar, diğer platformlarda Google Maps arama bağlantısı kullanılır. Konum izni istenmez.
- Arama ve e-posta sistem uygulamasına devredilir; otomatik mesaj gönderilmez. Telefon/e-posta/WhatsApp olmayan emülatörlerde açılamama beklenebilir.
- Dış uygulamalar yalnızca kullanıcı ilgili düğmeye bastığında seçilen veriyi alır.

## Doğrulama
Teslim ortamında Flutter/Dart yok; analyze/test ve gerçek cihaz testleri çalıştırılmadı. Bağlantı doğrulama ve güncel alan/numara seçimi için 6 test eklendi.
